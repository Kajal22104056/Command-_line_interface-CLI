Built like a real CLI product

Every command maps to a practical workflow: capture work, sort by urgency, search fast, and keep history on disk.

add

Priority + due dates

Create tasks with Low, Medium, or High priority and optional YYYY-MM-DD deadlines.

list

Color-coded output

High is red, Medium is yellow, Low is green. Completed tasks stay hidden unless you ask.

prioritize

Smart sorting

Orders pending work by priority first, then the nearest due date.

search

Keyword lookup

Finds matches across pending and completed lists without leaving the terminal.

complete / delete

Safe mutations

Validates task numbers before updating state, then writes the store back to disk.

tasks.txt

Persistent storage

Plain-text format, UTF-8, no database, no dependencies. Easy to inspect and version.

How the system works

A small, readable pipeline that interviewers can follow in one sitting.

01

Parse

argparse builds subcommands, flags, and validated due dates.

02

Load

tasks.txt is split into pending and completed records.

03

Act

Add, list, complete, delete, search, or sort in memory.

04

Save

Only successful writes persist, so bad input never corrupts the file.

Commands you can put in a demo

Clone the repo, then run these from the project folder.

python3 task_manager.py add "Ship portfolio" --priority high --due-date 2026-09-20

Add a high-priority task with a deadline.

python3 task_manager.py list --show-completed

Show pending work and finished tasks together.

python3 task_manager.py prioritize

Sort by High → Medium → Low, then due date.

python3 task_manager.py search resume

Find tasks by keyword across both lists.
